# Source index

What has been read into the profile, and what each source taught it. A later session reads this first, so it doesn't re-ingest what it already knows.

**Empty.** Nothing has been ingested yet. An example of a filled-in index: [`examples/ogilvy/sources-index.md`](../../../examples/ogilvy/sources-index.md).

|  |  |  |  |  |  |

Provenance is `hand`, `assisted`, `drafted` or `unknown` — see `config.yaml`. Fill it in at ingest time, not later: it decides how much of the source counts as evidence, and nobody remembers a year afterwards.

Add a row for every accepted refresh. The "what the profile learned" column is the important one — it is how you later spot a trait that no recent source supports, which is how profiles rot.

Mark pieces you consider off-voice rather than leaving them out. Knowing which of your own writing you dislike is useful signal.

## Not yet covered

Keep an honest list here of what the profile has no evidence for — languages, genres, registers. The skill reads it and says so on delivery instead of guessing.
